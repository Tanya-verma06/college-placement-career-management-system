# PlacementHub

PlacementHub is a College Placement and Career Management System designed to help students, recruiters and administrators manage placement activities.

## Features

- Student Registration and Login
- Role-Based Authentication
- Job Listing and Search
- Job Application Management
- Student Profile Management
- Career Recommendation
- Skill Gap Analysis
- Recruiter Job Posting
- Admin Management Panel

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage

## User Roles

### Student
- View available jobs
- Apply for jobs
- Track applications
- Update profile
- Get career recommendations
- Analyze skill gaps

### Recruiter
- Post job opportunities
- View posted jobs
- Manage applications

### Admin
- Manage users
- Manage jobs
- View applications
